# macOS 版本验收清单

适用于拾音 AI `0.5.1` Apple Silicon Mac 内部测试。自动化流程已经验证 DMG 能挂载、应用能启动、本地模型可加载，且覆盖安装和删除应用后测试数据仍保留；真实麦克风、系统声音、权限弹窗、全局快捷键和长会议需要在实体 Mac 上人工验收。

## 1. 安装与数据确认

- [ ] “关于拾音 AI”或应用信息显示版本 `0.5.1`。
- [ ] 历史会议数量与升级前一致。
- [ ] 抽查一场旧会议，录音、逐字稿、发言人姓名和总结均可打开。
- [ ] 主界面启动后停在空白会议准备页，醒目显示“开始会议”。
- [ ] 退出并重新打开应用后仍能正常加载历史会议。

## 2. 麦克风会议

- [ ] 选择“仅麦克风”，设备名称正确且输入电平随讲话变化。
- [ ] 连续讲话至少 2 分钟，逐字稿持续出现，没有明显停顿或重复片段。
- [ ] 中文、英文、数字及常用专业简称的基本识别可用。
- [ ] 结束会议后 WAV 录音可以回听，时间定位可用。
- [ ] 拒绝或暂未配置 MiniMax 时，录音与逐字稿仍能保存。

## 3. 系统声音与混合录制

- [ ] 播放一段带对白的线上会议或本地视频，选择“仅系统声音”。
- [ ] 首次使用时，macOS 的“屏幕与系统音频录制”权限提示清晰；授权并重开后可采集声音。
- [ ] 选择“系统声音 + 麦克风”时，两路声音都能进入逐字稿。
- [ ] 佩戴耳机测试混合模式，不出现明显回声或重复转写。
- [ ] 暂停外部声音后，界面能正确反映静音状态。

## 4. 发言人与逐字稿整理

- [ ] 按会议规模选择 6、12 或 20 人上限。
- [ ] 至少两人轮流讲话，同一人的多数片段能聚在一起。
- [ ] 手动修改发言人姓名后，同场记录全部更新。
- [ ] 下一场会议遇到相同发言人时显示“声纹匹配”；置信度不足时保留普通编号。
- [ ] 正序、倒序切换正确，重开应用后仍记住选择。
- [ ] 口语词过滤、全局查找替换、预览与撤销可用，原始版本可以恢复。

## 5. MiniMax、导出与 Obsidian

- [ ] MiniMax Key 重启后仍显示“已配置”，界面不会回显完整密钥。
- [ ] AI 总结能够生成决策、风险和行动项；失败时逐字稿不丢失。
- [ ] Markdown、网页报告和复制 Markdown 均可用。
- [ ] 手动同步到 Obsidian 后文件位于正确 Vault，标题和正文完整。
- [ ] 启用自动同步后，新完成的会议能生成或更新对应笔记。

## 6. 快捷键与稳定性

- [ ] `Control + Option + M` 能从其他应用唤回拾音 AI。
- [ ] `Control + Option + R` 能开始或结束听记。
- [ ] 关闭窗口后应用仍在后台运行；从 Dock 或快捷键可以重新打开。
- [ ] 完成一次不少于 30 分钟的真实会议，期间没有异常退出或转写停止。
- [ ] 异常关闭应用后重新打开，已保存的会议和逐字稿仍在。

## 7. 建议反馈格式

```text
应用版本：
macOS 版本与 Mac 型号：
会议人数：
录音来源：麦克风 / 系统声音 / 混合
会议时长：
问题出现时间：
实际表现：
期望表现：
是否可以稳定复现：
截图或脱敏日志：
```

请勿发送 MiniMax API Key、包含敏感信息的完整录音或未脱敏逐字稿。
