# Windows 版本验收清单

适用于拾音 AI `0.5.1` Windows x64 内部测试。自动化流程负责证明安装包能构建、安装、启动并加载本地模型；真实麦克风、声卡回环、快捷键和长会议仍需在同事的 Windows 电脑上人工验收。

## 1. 获取经过验证的安装包

1. 打开 GitHub 仓库的 **Actions → Windows build and smoke test**。
2. 选择结论为绿色 `Success`、提交与当前版本一致的运行记录。
3. 下载 `shiyin-ai-windows-<提交号>` artifact。
4. 解压后核对：
   - `拾音 AI Setup 0.5.1.exe`
   - `SHA256SUMS-windows.txt`
   - `windows-smoke-result.json`
5. 在 PowerShell 中校验安装包：

```powershell
Get-FileHash ".\拾音 AI Setup 0.5.1.exe" -Algorithm SHA256
Get-Content ".\SHA256SUMS-windows.txt"
```

两处 SHA-256 必须一致。当前安装包未做商业代码签名，Windows SmartScreen 可能显示“未知发布者”；只使用项目 GitHub 生成且校验一致的安装包。

## 2. 首次安装与启动

- [ ] 安装程序能选择目录并正常完成。
- [ ] “关于拾音 AI”显示版本 `0.5.1`。
- [ ] 主界面能正常打开，不出现空白页或后台启动失败。
- [ ] 左下角显示本地后台连接状态。
- [ ] 关闭窗口后应用保留在系统托盘；从托盘可以重新打开或退出。
- [ ] `Ctrl + Alt + M` 能打开应用。
- [ ] `Ctrl + Alt + R` 能开始或结束听记；如被其他软件占用，界面应显示提醒。

## 3. 现场会议：麦克风

- [ ] 选择“仅麦克风”，能看到正确的麦克风设备名称。
- [ ] 连续讲话 30 秒以上，输入电平有变化且逐字稿持续出现。
- [ ] 中文、英文、数字和常用专业词的基本识别可用。
- [ ] 结束会议后 WAV 录音可以回听，时间定位可用。
- [ ] 未配置 MiniMax 时，会议和逐字稿仍能保存。

## 4. 线上会议：Windows 电脑声音

- [ ] 播放一段有对白的会议音频，选择“仅电脑声音”。
- [ ] 应用能直接采集 Windows 系统播放声音；共享画面不会保存到会议数据，也不会上传。
- [ ] 关闭或暂停外部声音后，应用能显示静音提醒。
- [ ] 选择“电脑声音 + 麦克风”时，两路声音都能进入逐字稿。
- [ ] 混合模式佩戴耳机后，不出现明显重复转写或回声。

## 5. 发言人与逐字稿

- [ ] 选择符合会议规模的 6、12 或 20 人上限。
- [ ] 同一位发言人的多数片段能聚在一起。
- [ ] 手动修改发言人姓名后，同场记录全部更新。
- [ ] 下一场会议遇到相同发言人时出现“声纹匹配”；不确定时仍显示普通编号。
- [ ] 正序、倒序切换正确，重开应用后仍记住选择。
- [ ] 口语词过滤、查找替换、预览与撤销可用，原始记录不被覆盖。

## 6. MiniMax 与导出

- [ ] MiniMax Key 能保存，重启后仍显示“已配置”，界面不会回显完整密钥。
- [ ] 正式总结能生成决策、风险和行动项；失败时错误信息可理解且逐字稿仍保留。
- [ ] Markdown、网页报告和复制 Markdown 均可用。
- [ ] 如果 Windows 电脑安装了 Obsidian，手动保存和自动同步能找到正确 Vault。

## 7. 更新与数据保护

在旧版中先保留至少一场测试会议，再安装 `0.5.1`：

- [ ] 覆盖安装后历史会议数量不变。
- [ ] 旧会议的录音、逐字稿、人工姓名和总结仍可打开。
- [ ] 本机常用发言人匹配仍可使用。
- [ ] “本机存储”可以创建完整备份并从备份恢复缺失会议。
- [ ] 卸载应用不会自动删除 `%APPDATA%\拾音 AI\` 中的会议数据。

## 8. 建议反馈格式

```text
应用版本：
Windows 版本：
电脑与声卡/耳机：
会议人数：
录音来源：麦克风 / 电脑声音 / 混合
会议时长：
问题出现时间：
实际表现：
期望表现：
是否可以稳定复现：
截图或脱敏日志：
```

请勿发送 MiniMax API Key、包含敏感信息的完整录音或未脱敏逐字稿。
